# mr-skala – plugin Obsidiana

Instalacja: skopiuj foldery/pliki `main.js`, `manifest.json`, `styles.css` do
`<TWÓJ_VAULT>\.obsidian\plugins\mr-skala\`, potem w Obsidianie:
Ustawienia → Wtyczki społecznościowe → wyłącz tryb ograniczony → włącz „Skale i kalkulatory”.

Źródła: `src/` (skala-core.ts jest kopią z quartz/components/scripts/skala-core.ts —
po zmianie wersji na stronie trzeba przebudować plugin).
